# Sistema Web para Petshop
## Fase 1

Projeto em desenvolvimento para a disciplina Fundamentos de Sistemas Web.

O projeto consiste na criação de um sistema web para petshop utilizando HTML.

A página criada destaca estruturas básicas da linguagem HTML como cabeçalho (header), corpo da página (body) e rodapé (footer).

 ### Funcionalidades:
 - Exibição de informações sobre o petshop
 - Exibição dos serviços ofertados, com descrição e valores.
 - Exibição dos produtos oferecidos, com descrição e valores. 
 - Navegação entre seções da página.
 - Formulário de contato demonstrativo, contendo campos para nome, e-mail e mensagem.

Obs.: o formulário de contato possui finalidade ilustrativa. Mesmo permitindo o preenchimento dos campos, não realiza o envio de mensagens, pois não possui integração com serviços de processamentos de formulários.
